# SongStash 0.1.0-beta.1

## First beta

- Local music discovery library
- Direct local Shazam history import on Mac
- Repeated recognitions preserved as separate finds
- Import preview, progress, and results
- File import and manual song entry
- Library, Details, and Find History
- CSV and JSON export
- Local backup
- Preferred music service links
- English and Russian
- Four themes with Follow System
- Local-first storage

## Focus for this beta

Please pay special attention to first launch and installation, Shazam imports
on Macs with different history sizes, repeated recognitions, preview accuracy,
stability after restart, backup and export, and layouts in smaller windows.

## Known limitations

- Beta software for Apple Silicon Macs running macOS; not notarized.
- Shazam import depends on Apple's local database format and may change after
  macOS or Shazam updates.
- No cloud sync, built-in music recognition, or automatic updater.
